# LedgerSense
LedgerSense is an AI audit and tax-compliance copilot for Indian businesses. Kimi vision reads receipts and GST invoices; deterministic code matches bank CSVs, checks GSTINs, ITC blocks, cash limits and 80C/80D, and halts on high-risk items until an auditor signs off. Outputs books and draft ITR JSON. Only receipt images leave the machine.
